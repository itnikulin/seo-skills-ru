# Внешние ссылки

Возьми экспорт ссылок или явно укажи, какая часть профиля доступна. Нормализуй хосты, сохрани исходный и конечный URL, анкор, контекст, атрибут ссылки и дату наблюдения. Разбери потери: исчез источник, удалена ссылка, сломана цель, изменён редирект.

Сопоставь упоминания бренда и страницы, ссылающиеся на материалы конкурентов. Проверь тематическую связь, реальную аудиторию, редакционный смысл и наличие собственного материала, который стоит процитировать. Для битой цели предложи восстановление или релевантную замену. Для упоминания без ссылки подготовь основание для обращения.

Выдай приоритетный реестр «страница-источник / возможность / целевая страница / доказательство / действие». Низкая сторонняя оценка домена сама по себе недостаточна для удаления ссылки. Внешнюю переписку веди только по отдельному поручению.
