# Каталоги и масштабирование

Раздели URL на товары, категории, варианты, фильтры и комбинации. Для каждого шаблона сопоставь отдельный спрос, наличие реального предложения, уникальные данные и стоимость поддержки. Для фасета «бренд + размер» проверь, есть ли подходящие товары, самостоятельная задача и внутренний путь к странице.

Для карточки сравни видимую цену, валюту, варианты и наличие с Offer и фидом, если он есть. Для временно распроданного и снятого навсегда товара задай разные сценарии с учётом возможного возвращения и релевантных замен. Для шаблона проверь пустые данные, дубли и почти одинаковые страницы до массового запуска.

Верни матрицу правил «класс URL / условие публикации / индексация / canonical / внутренние ссылки / поведение при пустых данных». Выбери пилотную группу, дай проверку для каждого пограничного случая и критерий расширения по качеству, индексации и спросу.
