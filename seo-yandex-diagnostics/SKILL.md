# Диагностика Яндекса

Определи дату перелома, главный адрес сайта, регион, тип страниц и затронутый показатель. Запроси только недостающую выгрузку. Начни с двух одинаковых по длительности периодов с одинаковым составом дней недели. Для сезонного товара добавь годовое сравнение.

| Наблюдение | Что проверить дальше |
|---|---|
| Клики Вебмастера стабильны, визиты из Яндекса упали | Проверь счётчик на затронутых шаблонах, согласия, редиректы, фильтры и модель атрибуции. Сопоставь тенденции, учитывая разные единицы учёта. |
| Снизились показы | Разложи изменение по кластерам, регионам и типам страниц. Сопоставь спрос в Вордстате с динамикой позиции показа и количеством страниц в поиске. |
| Показы стабильны, кликов меньше | Сравни CTR внутри одинаковых запросов, регионов и устройств. Посмотри сниппет и состав выдачи. Проверь изменение состава запросов до интерпретации среднего CTR. |
| Выпал шаблон URL | Выбери выпавший и сохранившийся URL одного типа. Сопоставь HTTP, robots, meta robots, canonical, дату обхода и статус каждой страницы в Вебмастере. |
| Поступило сообщение о нарушении | Приведи точную формулировку, область действия и дату. Предложи устранение причины, проверку исправления на выборке и повторную проверку в кабинете владельца. |

Возьми клики, показы и позиции из Вебмастера, а визиты, посадочные, цели и выручку — из Метрики с сегментом переходов из поиска Яндекса. Отдельно проверь, менялась ли настройка цели. Ухудшение глубины или отказов на мобильном устройстве подсказывает, где воспроизвести проблему. Для утверждения о санкции требуется подтверждение в кабинете.

В результате укажи вклад сегментов в абсолютную потерю, доказанные причины, конкурирующие объяснения и одну проверку, которая поможет выбрать между ними. При наличии только публичного URL покажи доступные наблюдения и перечисли поля нужной выгрузки. [Диагностика в Вебмастере](https://yandex.ru/support/webmaster/ru/service/site-diagnostics)
