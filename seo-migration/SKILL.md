# Переезд

Собери старые адреса из sitemap, обхода, посадочных с трафиком и источников внешних ссылок. Сохрани базовые метрики по шаблонам и поисковикам. На каждый старый URL подбери наиболее близкий по намерению новый URL, решение об удалении или ручную проверку. Пометь конфликты многих старых страниц с одной целью.

Проверь матрицу старых и новых вариантов хоста, HTTP/HTTPS, параметров и языковых версий. Для постоянного переноса проверь прямой постоянный редирект, индексируемую конечную страницу, внутренние ссылки, канонический адрес, sitemap и hreflang. Удаление без замены требует осмысленного ответа 404/410. Для смены домена включи проверку прав на оба адреса и применимость инструментов переезда в каждой панели.

Отдай карту со столбцами «старый URL / решение / цель / ожидаемый код / фактическая цепочка / владелец». После запуска проверь ключевые посадочные, ошибки и индексацию обоих хостов. Сигнал для срочного исправления — массовый редирект важных URL на нерелевантную страницу или блокировка нового шаблона.
