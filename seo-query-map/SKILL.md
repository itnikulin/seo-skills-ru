# Семантика и архитектура

Собери существующие запросы и URL из Вебмастера или Search Console, добавь спрос из Вордстата либо доступного поставщика. Сохрани источник, регион, период и тип частотности. При отсутствии чисел маркируй фразы как кандидаты.

Проверь выдачу спорных фраз в целевом регионе. Определи задачу пользователя и преобладающий тип результата (категория, карточка, услуга, инструкция, сравнение). Объединяй фразы с общей задачей и похожими результатами. Если один запрос приводит на несколько страниц, проверь смену URL по датам и различие намерений до вывода о каннибализации.

Собери карту «кластер / намерение / примеры запросов / текущий URL / сохранить, обновить, объединить или создать / родительская страница / внутренняя ссылка / свидетельство». Приоритизируй незакрытый спрос с учётом коммерческой ценности и возможности дать лучший ответ. Для объединения страниц укажи судьбу старых адресов.
