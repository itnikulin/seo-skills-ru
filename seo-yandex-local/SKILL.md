# Региональность и коммерческая выдача

Составь матрицу «запрос × город × целевая страница». Разбери отдельно точку обслуживания, выездную услугу и доставку в регион. Для каждого случая зафиксируй, что клиент действительно может получить по указанному адресу или в указанной зоне.

Сверь регион главного адреса в Вебмастере, карточку филиала в Яндекс Бизнесе и страницу на сайте. Сопоставь название, телефон, часы, адрес, условия обслуживания. Проверь, может ли робот и пользователь открыть нужную страницу по прямой ссылке без принудительного переключения города по IP. Для сети филиалов сравни два действующих филиала и город только с доставкой. Основанием для отдельной страницы могут быть местные цены, запас, сроки, сотрудники или реальные кейсы.

Пройди путь от выдачи до заказа на телефоне. Для товара проверь цену, наличие, стоимость доставки и возврат. Для услуги проверь предмет работ, условия расчёта стоимости, подтверждение опыта и доступность записи. Сопоставь барьеры с данными целей Метрики, если они доступны.

Выдай таблицу «город / запрос / URL или карточка / расхождение / кому исправить / как проверить». Эффект на позиции сайта, переходы из Карт и заявки измеряй раздельно. [Региональность сайта](https://yandex.ru/support/webmaster/ru/site-geography/site-region)
